# Rice Ordering & Billing System

A simple C# Windows Forms application developed using Visual Studio to calculate the total price of rice orders based on the selected rice type, quantity, and additional options.

## Features

- Select different rice types
- Enter the required quantity
- Select additional options, beverages & desert.
- Calculate the total order price
- Simple and user-friendly Windows Forms interface

## Technologies Used

- C#
- Windows Forms
- Visual Studio

## Project Type

C# Windows Forms Project
